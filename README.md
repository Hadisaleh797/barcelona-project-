# FC Barcelona Website Project ⚽

This is my **graduation project** for my web development course.

The website is a mini fan page dedicated to **FC Barcelona**, created using **HTML, CSS, and JavaScript** only — no frameworks or libraries.

---

## 🌍 Website Pages
The project contains multiple pages:
- **Home** – Quick introduction and facts about FC Barcelona.
- **About** – History, stadium info, and background of the club.
- **Achievements** – All major trophies and titles won.
- **Players** – Stats and details about top 10 legendary players.
- **Quiz** – Interactive quiz to test your Barça knowledge.
- **Contact** – Basic contact or info section.

---

## 🎨 Technologies Used
- HTML (structure)
- CSS (design & styling)
- JavaScript (quiz interaction and dynamic parts)
